# Emir Tiryaki Portfolio

Modern ve responsive bir kişisel portfolio websitesi. React, TypeScript ve Tailwind CSS kullanılarak geliştirildi.

## Teknolojiler

Bu proje şu teknolojilerle geliştirildi:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Kurulum

```sh
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev
```

## Özellikler

- Modern ve responsive tasarım
- Dark/Light tema desteği
- Animasyonlu bileşenler
- SEO optimizasyonu
- Hızlı yükleme süreleri
