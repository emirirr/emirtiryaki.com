# 🚀 Emir Tiryaki - Portfolio Website

Modern ve responsive bir kişisel portföy web sitesi. Full Stack Developer olarak deneyimlerimi, projelerimi ve yeteneklerimi sergileyen profesyonel bir platform.

## ✨ Özellikler

- 🎨 **Modern Tasarım** - Shadcn/ui ve Tailwind CSS ile oluşturulmuş temiz ve modern arayüz
- 📱 **Responsive** - Tüm cihazlarda mükemmel görünüm
- ⚡ **Hızlı** - Vite ile optimize edilmiş performans
- 🌙 **Dark/Light Mode** - Otomatik tema desteği
- 🔗 **Sosyal Medya Entegrasyonu** - Tüm platformlarda kolay erişim
- 📊 **Proje Vitrini** - Detaylı proje açıklamaları ve teknoloji stack'leri
- 🏢 **Marka Portföyü** - Oluşturduğum markaların tanıtımı
- 📧 **İletişim Formu** - Kolay iletişim imkanı

## 🛠️ Teknolojiler

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS, Shadcn/ui
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Deployment**: Vercel/Netlify

## 📁 Proje Yapısı

```
src/
├── components/          # UI Bileşenleri
│   ├── ui/            # Shadcn/ui bileşenleri
│   ├── Hero.tsx       # Ana sayfa hero bölümü
│   ├── Skills.tsx     # Yetenekler bölümü
│   ├── Projects.tsx   # Projeler vitrini
│   ├── Brands.tsx     # Marka portföyü
│   ├── SocialMedia.tsx # Sosyal medya linkleri
│   ├── Contact.tsx    # İletişim formu
│   └── Footer.tsx     # Footer
├── pages/             # Sayfa bileşenleri
│   ├── Index.tsx      # Ana sayfa
│   └── Projects.tsx   # Projeler sayfası
├── data/              # Veri dosyaları
│   └── projects.ts    # Proje verileri
├── hooks/             # Custom hooks
├── lib/               # Yardımcı fonksiyonlar
└── assets/            # Resimler ve medya
```

## 🚀 Kurulum

```bash
# Repository'yi klonlayın
git clone https://github.com/emirirr/emirtiryaki.com.git
cd emirtiryaki.com

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Production build alın
npm run build
```

## 📈 Geliştirme Süreci

Bu proje, modern web geliştirme standartlarını takip ederek geliştirilmiştir:

1. **Tasarım**: Figma ile wireframe ve mockup'lar

3. **Styling**: Tailwind CSS ile utility-first yaklaşım
4. **UI Components**: Shadcn/ui ile tutarlı tasarım sistemi
5. **Performance**: Vite ile hızlı build ve development
6. **Deployment**: Vercel ile otomatik deployment
